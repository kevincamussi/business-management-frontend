# Business Management – Frontend

A responsive and modern web application for managing business operations such as expenses, employees, holidays, and more.  
Built using **Next.js, TypeScript, and TailwindCSS** with a clean, scalable architecture.

🔗 **Live Demo:** https://holiday-planner-frontend-five.vercel.app

---

## 🚀 Tech Stack

- **Next.js 15** + **TypeScript**
- **TailwindCSS**
- **Axios** for API integration
- **ESLint** + **Prettier**
- **FullCalendar** for scheduling UI
- **App Router** structure with modular architecture
- **JWT Authentication**

---

## 📦 Features

✔ Create, edit, and delete holiday schedules  
✔ Autocomplete suggestions for departments and employees  
✔ Responsive and interactive calendar UI  
✔ Login & authentication flow with JWT  
✔ Integration with FastAPI backend (REST API)  
✔ Clean folder structure with isolated modules (auth, calendar, register, etc.)

---

## ⚙️ Environment Setup

Create a `.env` file in the project root:

.env
NEXT_PUBLIC_API_URL=http://localhost:8000

git clone https://github.com/kevincamussi/business-management-frontend.git  
cd holiday-planner-frontend  
npm install  
npm run dev  
Frontend will be available at:  
👉 http://localhost:5173
